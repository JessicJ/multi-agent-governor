## 这些数字能说明什么

它们证明冻结的运行、隔离、扩容、停止、用量记录、确定性聚合和评分链路
在七个真实历史任务上完整工作；也描述了 `pilot-v2` 在这批单文件变更、
1–4 Agent 校准区间内的行为。

它们不能证明 Governor 对新项目普遍有效，也不能证明 4 个 Agent 对任意
项目足够：

- 任务及真值在仓库中公开，只在运行时隔离；
- 每任务只有一次重复；
- 全部任务都是本批次前冻结的较小历史变更；
- 评分裁决不是独立、隐藏组别的人工盲审；
- adaptive 在全部任务上都使用 2 个 Agent，没有覆盖更高扩容层级。

更强结论需要新的未见任务、独立盲审、多次重复，以及另行预注册的更大
变更和 `max-8` 压力实验。
