# Support

Multi-Agent Governor is experimental software.

- Read [README.md](README.md) for installation and usage.
- Read [docs/runtime-control.md](docs/runtime-control.md) for execution and
  safety boundaries.
- Read [evals/README.md](evals/README.md) for the evaluation workflow.
- Open a GitHub Issue for a reproducible bug or documentation problem.

When requesting help, include the package version, Python version, operating
system, command, sanitized configuration, expected result, and complete error
message. Remove credentials, private source code, truth cards, and Agent traces
that contain sensitive data.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md) and must not be
posted publicly.
